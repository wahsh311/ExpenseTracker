#  Expense Tracker (iOS App)

A premium, sleek, and highly interactive personal finance management application built exclusively for iOS. This app empowers users to track their daily expenses, monitor their "Safe to Spend" daily limit, and visualize their financial habits through dynamic charts.

##  Features

*   **Smart Dashboard:** Calculates your "Safe to Spend" daily amount dynamically based on your monthly salary, fixed expenses, and days remaining in the month (with negative balance alerts).
*   **Interactive Charts:** 
    *   **Weekly Trend:** A swipeable line chart tracking spending trends over the past 7 days.
    *   **Category Breakdown:** A dynamic pie chart with filtering options (Day, Week, Month) to analyze spending distribution.
*   **Custom UI/UX:** Features a modern, ultra-premium **Glassmorphism** design language across all screens, complete with a custom numeric keypad and haptic feedback.
*   **Data Persistence:** Utilizes Apple's latest **SwiftData** framework for fast, offline, and secure data storage.
*   **CSV Export:** Seamlessly export all expense history to a `.csv` file for external analysis (e.g., Excel, Numbers).
*   **Category Management:** Add custom categories with emojis to personalize your expense tracking.
*   **Swipe Actions & History:** Browse chronological expense history grouped by month, featuring native swipe-to-delete functionality.

##  Tech Stack & Architecture

*   **Framework:** SwiftUI
*   **Database:** SwiftData
*   **Data Visualization:** Swift Charts
*   **Architecture:** MVVM (Model-View-ViewModel)
*   **Design Pattern:** Clean Code, Modular Components, Custom ViewModifiers (GlassEffect)
